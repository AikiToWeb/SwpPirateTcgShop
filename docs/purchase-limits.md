# 계정당 구매 한도

상품별로 SWP 계정의 누적 구매 가능 수량을 설정합니다. `0`은 무제한이고, 설정 범위는 정수 `0~1,000,000`입니다. 기존 상품은 무제한으로 유지됩니다.

- 웹: **상점 관리 → 상품 등록/수정 → 계정당 구매 한도 → 저장**
- 설치형 0.4.0: **상품 선택 → 계정당 구매 한도 → 구매 한도 저장**. 로컬 상품은 등록할 때도 입력할 수 있습니다.

같은 SWP 계정이 해당 상품 ID로 주문한 수량을 합산합니다. 접수 및 수령 완료 주문을 포함하고 취소·예시 주문은 제외합니다. 하루 단위로 초기화하지 않습니다. 한도 설정 전의 주문도 계산하므로, 이미 한도 이상 구매했다면 추가 주문을 차단합니다. 기존 주문을 변경하거나 취소하지는 않습니다.

장바구니와 최종 주문에서 서버가 다시 검사합니다. 여러 주문으로 나누거나 동시에 요청해도 초과할 수 없습니다. 같은 주문 요청을 재전송한 경우 기존 주문을 반환하며 중복 구매로 계산하지 않습니다. 취소하면 그 주문 수량만큼 다시 구매할 수 있고 수령 완료는 한도를 복구하지 않습니다.

고객 화면에는 설정된 한도를 표시합니다. 로그인 계정의 남은 누적 수량을 브라우저에서 추정하지 않으며, 주문 시 서버가 실제 주문 기록을 확인합니다.

설치형의 매장 연결 모드 설정은 연결한 SWP 서버에 저장합니다. 로컬 테스트 모드는 계정 주문이 없으므로 설정값만 보존하며 주문 차단 기능은 적용되지 않습니다. 스마트스토어 구매자 계정과 SWP 계정을 연결하거나 네이버 주문에 이 한도를 강제하는 기능은 포함하지 않습니다.

웹/API 합본을 다시 빌드해 실행하고 설치형은 0.4.0으로 업데이트해야 합니다. 기존 상품·재고·주문·이력을 보존하는 DB 확장을 사용합니다. 설치형의 기존 데이터 경로는 유지됩니다.

검증은 운영 DB와 분리된 H2/SQLite에서 수행합니다. `inventory-desktop`의 `npm.cmd run test:store`는 실제 웹 관리자 설정, 설치형 매장·로컬 설정, 누적 초과 주문 차단, 중복 재요청, 취소 후 재구매를 확인합니다.
