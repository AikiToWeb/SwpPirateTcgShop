# 공식 카드 이미지 검색

상품 등록·수정에서 카드명 또는 카드번호로 공식 출처의 이미지를 찾고 선택할 수 있습니다. 검색은 상품을 저장하거나 기존 이미지를 변경하지 않습니다.

## 사용 순서

1. **상점 관리 → 상품 등록/수정**에서 게임·상품명·실제 상품 언어를 입력합니다.
2. **공식 카드 이미지 찾기**에서 검색어를 확인하고 **공식 이미지 검색**을 누릅니다. 카드번호로 검색하면 같은 이름의 다른 카드나 인쇄본을 구분하기 쉽습니다.
3. 후보의 카드번호·세트·언어·판본·피치와 이미지를 비교합니다. 확인되지 않은 항목은 표시하지 않습니다.
4. 실제 이미지가 로드된 후보에서 **이 이미지 선택**을 누릅니다. 이미지 주소와 저장 전 미리보기에만 적용됩니다.
5. 나머지 상품 정보와 미리보기를 확인한 뒤 기존 **저장** 버튼을 누릅니다.

상품명·게임·언어·검색어를 바꾸면 이전 검색 결과를 폐기합니다. 이전 편집 상품이나 오래된 조회 결과의 이미지를 현재 상품에 적용하지 않습니다. 이미지 선택으로 상품명·세트·가격·재고·언어·컨디션은 바뀌지 않습니다.

## 공식 출처와 언어

| 게임 | 출처 | 이번 지원 언어 | 구분 정보 |
| --- | --- | --- | --- |
| 원피스 카드게임 | [한국 공식 카드 검색](https://onepiece-cardgame.kr/cardlist.do) | 한국어 | 카드번호, 입수 세트, 일반/패러렐 이미지 |
| Flesh and Blood | [공식 Card Vault](https://cardvault.fabtcg.com/) | 영어 | 카드번호, 인쇄 세트, 포일/판본, 피치, 카드 면 |
| 리프트바운드 | [라이엇 한국어 카드 갤러리](https://playriftbound.com/ko-kr/card-gallery/) | 한국어 | 카드번호, 세트, 카드 이름·판본 |

FaB의 검색 언어 조건만으로 대표 인쇄본의 언어를 확정하지 않습니다. 공식 상세 인쇄본의 영어 여부를 확인합니다. 한국어 상품으로 조회하면 미지원 상태를 표시하며 영문 이미지를 한국어로 표시하거나 자동 대체하지 않습니다.

리프트바운드는 한국어 페이지에도 영어 카드가 섞여 있습니다. 한국어 이름과 공식 이미지 설명을 확인한 후보만 한국어로 반환합니다. 미출시·미번역 카드 이미지를 임의 번역하거나 URL 규칙을 추측해 생성하지 않습니다. 공식 갤러리가 제공하는 후보 범위 안에서만 조회합니다.

같은 이름의 카드도 번호·재판·패러렐·포일·피치가 다를 수 있습니다. 첫 결과를 자동 적용하지 않습니다. 이미지가 같아도 판매 단위·컨디션까지 일치한다고 간주하지 않습니다.

## 실패와 수동 입력

결과 없음, 지원하지 않는 언어/게임, 공식 출처 오류를 구분합니다. 결과가 없는 페이지에도 다음 페이지가 있을 수 있습니다. 공식 사이트가 변경되거나 차단되면 다시 조회하거나 기존 이미지 주소 입력으로 작업을 계속할 수 있습니다.

후보 이미지가 로드되지 않으면 해당 후보 선택을 막습니다. 기존 이미지 주소 입력은 유지하며 최대 1,000자입니다. 이미지 URL만 저장하며 이미지 파일을 운영 DB에 복사하지 않습니다. 공식 사이트의 이미지 제공 상태에 따라 외부 이미지가 나중에 변경되거나 로드되지 않을 수 있습니다.

## 서버와 검증

`POST /shop-api/admin/images/search`는 기존 관리자 권한·Origin·CSRF 검사를 적용합니다. 임의 URL을 입력받아 크롤링하지 않습니다. 고정 공식 호스트·경로와 확인한 이미지 CDN만 사용하며 응답 크기·시간·페이지·세부 조회 수·캐시를 제한합니다. 외부 실패를 성공 후보로 만들지 않습니다.

판매 목록에 예시 상품을 넣거나 운영 DB를 검색용으로 수정하지 않습니다. 테스트는 분리된 DB에서 수행합니다. 기존 원격 재고관리 프로그램은 웹 상점 관리에서 상품을 등록하므로 이번 기능을 그 등록 흐름에서 사용합니다. 로컬 테스트 프로그램에 새 이미지 필드를 추가하지는 않습니다.

### 실제 출처 통합 검증

합본 JAR을 빌드한 뒤 `inventory-desktop`에서 PowerShell로 실행합니다. Java 21의 `JAVA_HOME`이 필요합니다.

```powershell
$env:INVENTORY_TEST_CARD_IMAGES='1'
npm.cmd run test:store
```

임시 H2 DB에서 실제 관리자 화면으로 카드명을 검색하고 이미지를 선택·저장한 뒤 공개 목록의 이미지 주소와 로드된 크기를 검증합니다. 원피스는 `토니토니 쵸파` 검색 후 `OP08-001`로 인쇄본을 좁히며, FaB는 `Command and Conquer`, 리프트바운드는 `가렌, 강건`으로 확인합니다. 외부 공식 사이트에 연결할 수 있어야 합니다.

결과 JSON과 목록 화면 캡처는 Git에서 제외된 `inventory-desktop/test-output/store-*/`에 남습니다. 2026-11-03 검증에서 세 게임 모두 검색·선택·저장·목록 표시를 통과했습니다. 원피스의 `SAMPLE` 표시는 공식 이미지 자체에 포함되어 있습니다.
